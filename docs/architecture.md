## Архитектура приложения

Приложение имеет плоскую архитектуру - всё в одном файле `app/page.tsx`.

### Поток данных

```
data.json (статика)
    |
    v
page.tsx ("use client")
    |
    +-- useState: search, page, activeGenus, selected, sort
    +-- useMemo: filtered (фильтрация + сортировка)
    +-- useMemo: counts (количество по родам)
    |
    v
  Рендер: Hero или Catalog
```

### Два экрана

Переключение через `useState<"hero" | "catalog">("hero")`:

1. **Hero** - лендинг с полноэкранным фото, названием, поиском
2. **Catalog** - сетка карточек в стиле маркетплейса

## Компоненты (все в `app/page.tsx`)

### `Home` (экспорт по умолчанию, строка 246)
Корневой компонент. Управляет всем состоянием:
- `search` - поисковый запрос
- `page` - текущий экран ("hero" | "catalog")
- `activeGenus` - фильтр по роду (null = все)
- `selected` - выбранное растение для модалки
- `sort` - ключ сортировки

Содержит два return:
- `page === "hero"` -> Hero-экран
- иначе -> Catalog-экран

### `Card` (строка 37)
Карточка товара в каталоге. Показывает:
- Градиентный фон с эмодзи дерева (зависит от рода)
- Бейджи: "Мало" (qty <= 2), "Премиум" (price >= 4500)
- Кнопку "лайк" (при наведении)
- Цену, рассрочку, название, контейнер, количество

### `Detail` (строка 95)
Модальное окно с деталями товара. Три колонки:
- Левая: изображение (градиент + эмодзи)
- Средняя: хлебные крошки, название, характеристики
- Правая: цена, статус наличия, CTA-кнопки, доставка

Анимация появления: `animate-slideUp` (снизу вверх).

### `HeartButton` (строка 22)
Кнопка "лайк" с локальным состоянием. Состояние не сохраняется.

### Вспомогательные функции

| Функция | Строка | Назначение |
|---|---|---|
| `formatPrice` | 9 | Форматирование числа в русской локали |
| `sortPlants` | 238 | Сортировка массива растений |

### Константы

| Константа | Назначение |
|---|---|
| `GENUS_LABEL` | Русские названия родов: Abies->Пихта, Picea->Ель, Pinus->Сосна |
| `GENUS_GRADIENT` | Tailwind-градиенты для каждого рода |
| `GENUS_EMOJI` | Эмодзи деревьев для каждого рода |
| `SORT_OPTIONS` | Варианты сортировки каталога |

## Layout (`app/layout.tsx`)

- Шрифт: Inter (Latin + Cyrillic)
- Язык: `ru`
- Фон: `bg-cream` (кастомный цвет)
- Метаданные: заголовок и описание на русском
