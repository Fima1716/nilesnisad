# Дизайн-система и стилизация

## Подход

Tailwind CSS v4 через PostCSS. Кастомные цвета заданы в `app/globals.css` через `@theme`. Inline-стили Tailwind повсюду, без отдельных CSS-классов.

## Кастомная палитра

Определена в `app/globals.css`:

```css
@theme {
  --color-forest: #1b4332;       /* основной тёмно-зелёный */
  --color-forest-light: #2d6a4f; /* hover-состояние */
  --color-sage: #52b788;         /* акцентный зелёный */
  --color-sage-light: #95d5b2;   /* выделение текста */
  --color-sage-pale: #d8f3dc;    /* (не используется) */
  --color-cream: #faf9f6;        /* фон страницы */
  --color-warm: #f8f6f1;         /* (не используется) */
}
```

Использование: `bg-forest`, `hover:bg-forest-light`, `text-forest`, `bg-cream`.

## Градиенты карточек по роду

Каждый род имеет свой цветовой градиент для фона карточки:

| Род | Градиент |
|---|---|
| Abies (Пихта) | зелёный (`green-200` -> `emerald-100` -> `green-50`) |
| Picea (Ель) | голубой (`cyan-200` -> `sky-100` -> `blue-50`) |
| Pinus (Сосна) | жёлтый (`yellow-200` -> `amber-100` -> `orange-50`) |

## Стиль UI

Вдохновлён маркетплейсом Ozon:
- Sticky header с поиском и табами категорий
- Сетка карточек (2-6 колонок в зависимости от ширины)
- Карточки с hover-эффектами (тень, кнопка лайка)
- Модальное окно с тремя колонками на десктопе, sheet снизу на мобильном
- Фон каталога: `#f2f2f7` (серый)

## Анимации

- `animate-slideUp` - появление модального окна (0.3s ease-out, снизу вверх)
- `hover:scale-110` - увеличение кнопки лайка
- `group-hover:opacity-30 group-hover:scale-110` - эмодзи в карточке
- `group-hover:translate-x-1` - стрелка "Весь каталог"

## Адаптивность

- Мобильный: 2 колонки, sheet-модалка снизу, скрыты десктопные элементы
- Планшет: 3-4 колонки
- Десктоп: 5-6 колонок, трёхколоночная модалка, полный header

## Шрифт

Inter (Latin + Cyrillic), подключён через `next/font/google`, применяется как CSS-переменная `--font-inter`.
