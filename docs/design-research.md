# Ресёрч дизайна: магазины растений и хвойных

## Топ-референсы (от лучших к худшим)

---

### 1. Bloomscape (bloomscape.com) — ЭТАЛОН
**Что продают:** Комнатные растения, горшки, аксессуары (США)

**Почему лучший:**
- Нейтральные землистые тона (белый, серый, глина) — растения сами являются цветовым акцентом
- Lifestyle-фотография: растения в интерьерах с естественным светом, не на вырезанном фоне
- Карточки товаров: фото + название + размер + цена + бейджи ("Self-Watering", "EcoPot") + быстрое добавление в корзину
- Множество путей к покупке: по категориям, по коллекциям ("Best Sellers"), по условиям ("Low Light", "Pet-Friendly", "Easy Care")
- Фирменный сервис "Grow-How" — экспертная поддержка = доверие
- 30-дневная гарантия прямо в шапке

**Что взять:**
- Lifestyle-фото растений в контексте сада/участка
- Фильтрация по "характеру" растения (карликовое, плакучее, колонновидное)
- Бейджи на карточках (Редкое, Мало, Новинка)
- Чистый минимализм — белый фон, крупные фото, минимум шума

### 2. Conifer Kingdom (coniferkingdom.com) — ЛУЧШИЙ СПЕЦИАЛИЗИРОВАННЫЙ
**Что продают:** Хвойные, карликовые сорта, японские клёны (США)

**Почему хорош:**
- Мега-меню с фильтрацией по: виду, цвету хвои, форме кроны, скорости роста, зоне зимостойкости
- Цветовая палитра: зелёный (#6da081) + золотой (#f1cb82) — ботанический и премиальный
- Верхняя полоса: "45-day guarantee" + "Free gift on $50+" — моментальное доверие
- 600+ сортов, но навигация не перегружена

**Что взять:**
- Фильтр по зоне зимостойкости (критично для России)
- Фильтр по форме кроны: шаровидная, плакучая, колонновидная, стелющаяся
- Фильтр по скорости роста: карликовые, полукарликовые, стандартные
- Гарантия прямо в хедере
- Золотой акцент для премиальности

---

### 3. Conifers Garden (conifersgarden.com) — КОЛЛЕКЦИОННЫЙ
**Что продают:** Редкие хвойные, привитые, сеянцы (Венгрия, доставка по миру)

**Почему интересен:**
- Фокус на редкости: "211 из 615 видов под угрозой по IUCN"
- Позиционирование: "conservation through cultivation" — не магазин, а миссия
- Мультивалютность: 13+ валют, глобальная доставка
- Энциклопедия + журнал — контент-маркетинг для энтузиастов
- Категории: Rare Conifers, Grafted Conifers, Seedlings & Cuttings

**Что взять:**
- Контент-маркетинг: статьи про уход, описания видов
- Позиционирование как эксперт, а не просто магазин
- Если есть редкие виды — подчёркивать редкость и историю

**Минусы:**
- Аскетичный дизайн, мало визуальной иерархии
- Карточки товаров бедные: нет описаний, статуса наличия, размеров

### 4. Leon & George (leonandgeorge.com) — ЛЮКС
**Что продают:** Премиальные комнатные растения в керамике (США)

**Почему хорош:**
- Галерейный дизайн: растения как предметы искусства
- Минимализм: много воздуха, крупная типографика, спокойные цвета
- Каждый товар = растение + горшок + доставка + пожизненная поддержка
- Accessibility: крупный текст, высокая контрастность

**Что взять:**
- Подход "всё включено" (растение + контейнер + инструкция)
- Галерейная подача: одно большое фото > сетка мелких
- Пожизненная поддержка по уходу — сильный trust signal

## Выводы: что делать для "Ни лес ни сад"

### Визуальный стиль
- **Палитра:** тёмный лесной зелёный (уже есть: #1b4332) + золотой/янтарный акцент для премиальности + кремовый фон
- **Фото:** lifestyle-фото растений в саду/на участке, не вырезка на белом. Макро-детали хвои, текстура коры
- **Типографика:** крупная, жирная, с характером. Inter уже хорош, но можно рассмотреть serif для заголовков (премиальность)
- **Карточки:** крупное фото + цена + название + бейджи (Редкое/Мало/Новинка/Премиум) + быстрый лайк

### Фильтрация (ключевое для хвойных)
- По роду: Пихта / Ель / Сосна (уже есть)
- По форме кроны: шаровидная, плакучая, колонновидная, стелющаяся, подушковидная
- По скорости роста: карликовые / полукарликовые / стандартные
- По цвету хвои: зелёная, голубая, золотистая, вариегатная
- По цене: ползунок или диапазоны
- По наличию: в наличии / предзаказ
- По зимостойкости: зона USDA

### Страница товара
- Галерея фото (3-5 ракурсов + фото в ландшафте)
- Ботаническое название + русское название
- Характеристики: род, вид, сорт, форма, скорость роста, высота через 10 лет, зимостойкость
- Описание сорта (история, особенности)
- Цена + статус наличия + CTA
- Похожие сорта / "С этим покупают"
- Отзывы

### Уникальные фишки для нашего магазина
1. **"Размер через 10 лет"** — ключевая метрика для коллекционеров (как у Singing Tree)
2. **Бейдж "Коллекционный сорт"** — выделять редкие позиции
3. **Контент:** статьи про уход за привитыми саженцами, описания видов
4. **Гарантия приживаемости** — прямо в шапке (как у Conifer Kingdom)
5. **Сезонность:** предзаказ на следующий сезон, уведомления о поступлении
6. **Фото реальных растений** — не стоковые, а именно те экземпляры что продаются

### Чего избегать
- Стена одинаковых карточек без визуальной иерархии (Kigi)
- Сломанные/медленные фото (Kigi)
- Перегруженность элементами (Подворье)
- Устаревший дизайн (большинство русских питомников)
- Только текст без фото (Conifers Garden)
