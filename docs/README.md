# "Ни лес ни сад" - Обзор проекта

Каталог-витрина коллекционных хвойных растений (привитые саженцы в контейнерах). Это одностраничное клиентское приложение без бэкенда, базы данных или API. Вся информация о товарах хранится в статическом JSON-файле.

## Назначение

Сайт для питомника/продавца хвойных растений. Пользователь может:
- Просматривать каталог с карточками товаров (стиль маркетплейса Ozon)
- Фильтровать по роду (Пихта / Ель / Сосна)
- Искать по названию
- Сортировать (по цене, по названию)
- Открывать детальную карточку товара в модальном окне

Заказ происходит офлайн ("Написать для заказа"), корзины нет.

## Структура проекта

```
ni-les-ni-sad/
  app/
    layout.tsx       - корневой Layout (шрифт Inter, метаданные)
    page.tsx         - единственная страница, содержит ВСЮ логику и компоненты
    globals.css      - Tailwind + кастомная тема (цвета, анимация)
    data.json        - каталог: 72 растения
    favicon.ico
  public/
    hero.png         - фото для главного экрана (хвойное дерево)
    *.svg            - стандартные иконки Next.js (не используются)
  AGENTS.md          - инструкции для Claude
  CLAUDE.md          - ссылка на AGENTS.md
```

## Ключевые особенности

- **Один файл = всё приложение.** Вся UI-логика в `app/page.tsx` (~424 строки)
- **Нет маршрутизации.** Два "экрана" (Hero и Catalog) переключаются через `useState`, не через роутер
- **Нет серверных компонентов.** `page.tsx` помечен `"use client"`
- **Нет API / бэкенда.** Данные импортируются напрямую из JSON
- **Язык интерфейса** - русский
